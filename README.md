# ⚡ NIRVAN '26 — Technical Fest Portal

> **Where Ideas Become Innovation.**  
> *The official web portal for Graphic Era Hill University’s (Haldwani Campus) premier annual technical symposium.*

## 🎨 Design System & Visual Identity

NIRVAN '26 features a **Cyber-Industrial / Schematic Aesthetic** tailored for high-energy tech events:

* 🎨 **Color Palette**: Dark slate background (`#0A1220`) with accent copper (`#FF8A50`) and electric trace green (`#5FE3C0`).
* 📐 **Typography**: Technical mix of `Space Grotesk` (Headings), `Inter` (Body), and `IBM Plex Mono` (Labels/Code).
* 🕸️ **Schematic Grid**: Dynamic CSS grid background with ambient glowing noise gradients.
* ⚡ **Reduced Motion Support**: Respects system preferences via `@media (prefers-reduced-motion)`.



✨ Standout Features

 🕒 Interactive Hero Experience
* **Live Target Countdown**: High-precision JavaScript timer counting down to event kickoff (October 24, 2026).
* **SVG Campus Node Map**: Animated visual schematic displaying event zones with pulsed status indicators.

 🎪 Event Arena & Smart Discovery
* **Multi-Filter System**: Instant track filtering (`TECH`, `DESIGN`, `GAMING`, `FUN`, `LEARN`).
* **Real-time Live Search**: Instant DOM search across event titles and categories with zero latency.
* **Deep Specification Modals**: Interactive modal triggers displaying event fees, prize pools, eligibility criteria, and rules.

 📅 Dynamic Itinerary & Schedule
* **Day-by-Day View**: Toggle across Days 1, 2, and 3.
* **Contextual Dimming**: Schedule items auto-dim based on selected category tags, keeping focus on relevant sessions.

 👤 Keynote & Speaker Hub
* **Profile Cards**: Dynamic initials generation and speaker background cards.
* **Detailed Speaker Drawer**: View full speaker bios, corporate affiliations, and scheduled sessions.

📸 Dynamic Gallery & Lightbox
Interactive Grid: Visual history of past editions (`N'23`–`N'25`).
Lightbox Navigation: Cycle through event moments with modal pagination.

 📝 Client-Side Registration Pipeline
Zero-Dependency Form**: Accessible modal-driven registration form with instant validation feedback.



## 🛠️ Architecture & Tech Stack

This project is built as a **zero-dependency, single-file Web App** prioritizing performance, accessibility, and ease of deployment.
